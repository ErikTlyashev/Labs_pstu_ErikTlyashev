# Лабораторная работа №10, вариант 24
**Динамические массивы**

## Вариант
Сформировать массив строк. Удалить из него K первых строк.

## Решение
- Массив строк — динамический массив указателей `char**` (`new char*[n]`), каждая строка выделяется `new char[strlen(buf) + 1]`.
- Функции: `makeArray`, `printArray`, `removeFirst` (формирует новый массив из n − k указателей, освобождает первые k строк и старый массив), `freeArray`.
- Если K > n, удаляются все строки (массив пустой); K < 0 отвергается.
- Строки вводятся с клавиатуры (слова без пробелов).

## Сборка и запуск
```
g++ -std=c++17 -o lab10 lab10.cpp
./lab10
```

## Контрольные примеры
| № | Данные | Результат |
|---|---|---|
| 1 | n = 6: яблоко груша слива вишня персик абрикос; K = 2 | слива, вишня, персик, абрикос |
| 2 | n = 3: кот пёс лис; K = 5 | массив пуст |

## Выводы
- Память под строки и массив указателей выделяется `new` и освобождается `delete[]`; утечек нет.
- Массив-результат формируется переносом указателей, без копирования самих строк.

## Примечание
В методичке для варианта 24 есть неоднозначность: пункт «Удалить К последних строк» записан в одном абзаце с пунктом «Удалить одинаковые строки». Принято нумерование по абзацам: вариант 24 — «удалить К первых строк».
