# Лабораторная работа №3, вариант 24
**Вычисление функций с использованием разложения в степенной ряд**

## Вариант
- Функция: y = ln(1 / (2 + 2x + x²))
- Диапазон: −2 ≤ x ≤ −0,1, шаг h = (b − a)/k = 0,19 (k = 10, 11 точек)
- n = 40, точность ε = 0,0001
- Ряд: S = −(1+x)² + (1+x)⁴/2 − … + (−1)ⁿ·(1+x)²ⁿ/n

## Математическая модель
Так как 2 + 2x + x² = 1 + (1+x)², то y = −ln(1 + t), t = (1+x)². Разложение ln(1+t) даёт
a_k = (−1)ᵏ·tᵏ/k = c_k / k, где c_k = c_(k−1)·(−t), c₀ = 1.
Ряд сходится при −2 ≤ x ≤ 0, то есть на всём отрезке.
SN — сумма первых n = 40 слагаемых (арифметический цикл); SE — сумма до |a_k| < ε (итерационный цикл); Y — точное значение через `log`.

## Сборка и запуск

```
g++ -std=c++17 -o lab3 lab3.cpp
./lab3
```

## Выводы
- SN при n = 40 совпадает с точным значением во внутренних точках (погрешность не больше 5·10⁻¹⁰). На границах погрешность растёт: 2,4·10⁻⁶ при x = −0,1 и 1,2·10⁻² при x = −2, где t = 1 и ряд сходится условно и медленно.
- SE везде укладывается в ε = 0,0001 (максимум 5,0·10⁻⁵ при x = −2), так как для знакочередующегося ряда погрешность не превышает первого отброшенного слагаемого.
- Число слагаемых для SE сильно зависит от x: от 2 вблизи x = −1 до 10001 при x = −2.
- Рекуррентный пересчёт множителя (−t)ᵏ избавляет от возведения в степень на каждом шаге.
