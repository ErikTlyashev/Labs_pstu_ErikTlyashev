# Лабораторная работа №7, вариант 24
**7.1 Перегрузка функций, 7.2 Функции с переменным числом параметров**

## Вариант
- **7.1.** Перегруженные функции `removeEven`: а) для массива целых чисел удаляет все чётные элементы; б) для строки удаляет все чётные слова.
  *Допущение:* «чётные слова» — слова с чётными порядковыми номерами (2-е, 4-е, …), слова разделены пробелами.
- **7.2.** Функция `side` (длина стороны по координатам), `square` (площадь треугольника по вершинам), `squaren(n, ...)` — площадь выпуклого многоугольника по координатам вершин (переменное число параметров).

## Файлы
- `lab7_1.cpp` — часть 7.1, `lab7_2.cpp` — часть 7.2.

## Сборка и запуск
```
g++ -std=c++17 -o lab7_1 lab7_1.cpp && ./lab7_1
g++ -std=c++17 -o lab7_2 lab7_2.cpp && ./lab7_2
```

## Результаты
**7.1** (набор 1): массив `7 -4 12 3 0 -9 8 5 -2 11` → `7 3 -9 5 11`; строка `один два три четыре пять шесть семь` → `один три пять семь`.
Набор 2: массив `2 4 6 8` → пусто; строка `слово` → `слово`.

**7.2:**
| n | Вершины | Результат | Ожидаемо |
|---|---|---|---|
| 3 | (0;0), (4;0), (0;3) | 6 | 6 |
| 4 | (0;0), (4;0), (4;4), (0;4) | 16 | 16 |
| 5 | (0;0), (4;0), (5;3), (2;5), (−1;3) | 21 | 21 (формула Гаусса) |
| 6 | правильный шестиугольник, сторона 2 | 10.3923 | 6·√3 ≈ 10.3923 |

## Выводы
- Перегруженные функции различаются типами параметров; компилятор выбирает версию по фактическим параметрам.
- В `squaren` многоугольник делится диагоналями из первой вершины на n − 2 треугольника, площади считаются по формуле Герона через `side`.
- В списке `...` тип и число параметров не проверяются: координаты нужно писать как `double` (`4.0`, а не `4`).
