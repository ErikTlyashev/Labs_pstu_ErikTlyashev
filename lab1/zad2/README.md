## Лабораторная работа №1. Вариант 24

### Задание 2

**Выражения:**
1) `n++ * m`
2) `n++ < m`
3) `m-- > m`

**где n = a/b, m = b/a**

#### Для типа float

| № | Выражение | Результат | Пояснение |
|---|-----------|-----------|-----------|
| 1 | `n++ * m` | 1.0 | Произведение n и m, после n увеличивается на 1 |
| 2 | `n++ < m` | 0 (ложь) | n много больше m, после n увеличивается на 1 |
| 3 | `m-- > m` | 1 (истина) | m > m-1, после m уменьшается на 1 |

#### Для типа double

| № | Выражение | Результат | Пояснение |
|---|-----------|-----------|-----------|
| 1 | `n++ * m` | 1.0 | Произведение n и m, после n увеличивается на 1 |
| 2 | `n++ < m` | 0 (ложь) | n много больше m, после n увеличивается на 1 |
| 3 | `m-- > m` | 1 (истина) | m > m-1, после m уменьшается на 1 |

### Сводная таблица результатов

| Задание | Тип данных | Выражение | Результат |
|---------|------------|-----------|-----------|
| 1 | float | формула | 0.999999 |
| 1 | double | формула | 1.0 |
| 2 | float | `n++ * m` | 1.0 |
| 2 | float | `n++ < m` | 0 |
| 2 | float | `m-- > m` | 1 |
| 2 | double | `n++ * m` | 1.0 |
| 2 | double | `n++ < m` | 0 |
| 2 | double | `m-- > m` | 1 |

### Объяснение результатов

Здесь n = a / b = 10000000 (большое число), а m = b / a = 0.0000001 (очень маленькое число).

n++ * m — это n * m. По математике (a/b) * (b/a) = 1. Для double так и получается — 1.0. Для float может быть чуть-чуть меньше или больше из-за неточности.

n++ < m — это вопрос: «10000000 меньше, чем 0.0000001?» Конечно, нет. Поэтому ответ 0 (ложь). И для float, и для double одинаково.

m-- > m — это вопрос: «m больше, чем m минус 1?» Да, любое число больше, чем оно же минус 1. Поэтому ответ 1 (истина). Тоже одинаково для обоих типов.

### Вывод по обоим заданиям
Разница между float и double видна только там, где нужна высокая точность — например, при умножении очень больших чисел на очень маленькие. В обычных сравнениях (<, >) разницы нет, потому что там важна не точность, а сам факт «больше или меньше».
