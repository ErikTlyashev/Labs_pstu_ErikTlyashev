## Лабораторная работа №1. Вариант 24

### Задание 1

**при a = 1000, b = 0.0001**

| Тип данных | Результат |
|------------|-----------|
| float      | 0.999999  |
| double     | 1.0       |

### Объяснение результатов

Если посчитать формулу на бумаге, должно получиться ровно 1.

Но компьютер считает не идеально точно. Тип float хранит только 7 цифр после запятой, поэтому он может ошибиться и выдать 0.999999 вместо 1.0.

Тип double хранит 15–16 цифр, поэтому он считает точнее и выдаёт ровно 1.0.

### Вывод по обоим заданиям
Разница между float и double видна только там, где нужна высокая точность — например, при умножении очень больших чисел на очень маленькие. В обычных сравнениях (<, >) разницы нет, потому что там важна не точность, а сам факт «больше или меньше».
